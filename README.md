# Agnes 2.5 Pro Alpha

Official open-source model card for **Agnes 2.5 Pro Alpha**, Agnes AI's most capable multimodal reasoning model.

## Overview

Agnes 2.5 Pro Alpha is built for advanced coding, scientific problem solving, long-context analysis, multimodal understanding, and agentic workflows. It combines extended reasoning and tool calling with production-oriented throughput.

## Highlights

- **1M-token context window** with up to **65,536 output tokens**.
- Supports text and image understanding, extended reasoning, and tool calling.
- Designed for demanding coding, scientific, and agentic tasks.
- Published under the **Apache-2.0** license.
